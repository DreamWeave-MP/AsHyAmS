# DreamWeave Network

An index of DreamWeave mod sites: every project, release, dependency, capability and change it
has observed on independently published sites, rebuilt every six hours as a static website.

<https://dreamweave-mp.github.io/AsHyAmS/>

There is no DreamWeave server in the middle. Each project's own site, built with the
[DreamWeave Mod Template](https://github.com/DreamWeave-MP/DreamWeave-Mod-Template) or anything
else that speaks [the protocol](https://dreamweave-mp.github.io/DreamWeave-Mod-Template/guide/protocol/),
publishes `dreamweave.json` and a manifest per project. This index reads those sites, keeps what
they said in Git, notices what changes, and renders all of it as files any static host can serve.

- **Not a registry.** Project ids are chosen by authors, not allocated here. When two sites publish
  the same id, both claims are shown and neither wins.
- **Not a host.** Downloads go to publishers' own sources. Nothing is proxied or counted.
- **Not required.** If this index disappears, every mod stays discoverable, installable and
  verifiable from its own site.
- **Not the only one.** Anyone can run another index over the same sites.

## Run it

You need Rust (stable), [Zola](https://www.getzola.org/) 0.22.1 and Git.

```sh
cargo network refresh      # crawl every site in network/sources.toml into state/
cargo network build        # write the Zola site from state/
zola serve                 # look at it
```

`cargo network` is an alias for `cargo run --locked --release -p dreamweave-network --`. To start
from the published history instead of from nothing:

```sh
git fetch origin network-state && git worktree add state origin/network-state
```

| Command | Does |
|---|---|
| `cargo network inspect <url>` | Read a site the way the crawler does and report what it publishes. Writes nothing |
| `cargo network add <url> --note "…"` | Inspect a site, then enroll it in `network/sources.toml` |
| `cargo network refresh` | Crawl every enrolled site and update `state/`. Unreachable sites are state, not errors |
| `cargo network diff` | Print what the last refresh observed changing |
| `cargo network build` | Write Zola's content, view data and `network-data/` from the state |
| `cargo network check` | Validate the source list, curation and every invariant of the state |
| `cargo network check-site` | Check every local link and anchor in `public/` |

## Where things live

| Path | What |
|---|---|
| `network/sources.toml` | The sites this index reads. Changed by pull request |
| `network/curation.toml` | This index's own decisions, labelled as such on the site |
| `tools/dreamweave-network/` | The crawler, diff engine, network model and site generator (Rust) |
| `tools/dreamweave-network/schemas/` | The protocol's JSON Schemas, vendored with their provenance |
| `pages/` | The field manual and the join page |
| `templates/`, `sass/`, `static/` | Presentation, built on the Mod Template's (`UPSTREAM.md`) |
| `state/` | A worktree of the `network-state` branch: last good manifests, records, events |
| `content/`, `data/network/`, `static/network-*` | Generated by `build`; gitignored |
| `.github/workflows/network.yml` | Every six hours: refresh, build, deploy, commit the state |
| `.github/workflows/check.yml` | Every change: Rust gate, fixture site, new sources inspected live |

## Joining

Publish a DreamWeave site, then:

```sh
cargo network inspect https://you.github.io/your-mod/
cargo network add https://you.github.io/your-mod/ --note "What it is, in one line."
```

and open a pull request. Or [open an issue](https://github.com/DreamWeave-MP/AsHyAmS/issues/new?template=join.yml)
with the URL. The [join page](https://dreamweave-mp.github.io/AsHyAmS/join/) explains what review
means and what it does not.
